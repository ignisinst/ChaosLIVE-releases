# Політика конфіденційності ChaosLIVE by Cloud

Редакція 18.10.2026. Розробник: Cloud. Проєкт документа, без юридичної перевірки.
Звернення: https://github.com/ignisinst/ChaosLIVE-releases/issues — не надсилайте там
паролі, платіжні дані, приватні чати чи журнали без вилучення особистої інформації.
Перед масовим розповсюдженням Cloud має додати належні ідентифікаційні/контактні
дані володільця персональних даних та перевірити документи з юристом в Україні.

## Локальна робота
Програма зберігає налаштування, ім'я Minecraft, TikTok username, адресу/порт RCON,
пакети подій та діагностичні журнали у профілі Windows. RCON-пароль захищається
Windows DPAPI; застосунок розшифровує його лише для підключення. DPAPI не захищає
від процесів, запущених у тому самому обліковому записі користувача.
Локальний HTTP API працює на 127.0.0.1; браузерний dashboard/overlay за бажанням
залишаються доступними. RCON використовується для команд вашого Minecraft-сервера.
Не відкривайте локальний API в Інтернет без окремого захисту.

## Аудиторія TikTok
За вашим запуском TikTokLive та його мережеві залежності підключаються до TikTok і
сервісу підписання запитів, використовуваного TikTokLive/EulerStream. Їм видима IP-адреса.
Обробляються публічні ідентифікатори/імена глядачів, коментарі-команди, лайки,
подарунки, монети та пов'язані події для взаємодії з грою. Рейтинг і лічильники
поточної сесії скидаються при зупинці й новому запуску; останній стан сесії може
залишитися на диску після аварійного завершення до наступного запуску.
Старі файли статистики, резервні копії, журнали й ідентифікатори повідомлень для
захисту від повторів можуть зберігатися у профілі. Логи API/TikTok/Minecraft можуть
містити username і текст команди. Cloud не отримує їх автоматично.
Користувач-стрімер має забезпечити належну правову підставу та інформування своєї
аудиторії згідно з Законом України «Про захист персональних даних» №2297-VI.

## Реклама
Немає рекламної SDK, cookie-ідентифікаторів, fingerprinting, телеметрії, пікселів
обліку показів/кліків чи передачі ігрових/глядацьких даних рекламодавцям.
Коли явно увімкнена та налаштована пряма реклама, застосунок отримує JSON і статичне
зображення з HTTPS-сервера. Сервер/CDN бачить IP, час і User-Agent з версією програми
та може вести власні технічні журнали. Немає унікального ідентифікатора користувача.
Автоматичне повторне отримання — не частіше ніж раз на 6 годин під час роботи;
після завершення кампанії банер приховується. ads_enabled=false вимикає запити.
Без налаштованої кампанії рекламних запитів немає. Перехід за банером — лише вручну.

## Донати та оновлення
Кнопка monobank відкриває https://send.monobank.ua/jar/4q63EfWzGL у браузері після
вашого натискання. Банківські реквізити, сума і факт платежу не надходять у застосунок.
monobank та браузер обробляють дані за власними політиками.
Кнопка перевірки оновлень робить HTTPS-запит до GitHub API офіційного репозиторію;
GitHub бачить IP/час/User-Agent. Немає фонової перевірки чи автоматичної установки.

## Керування даними
Закрийте програму перед копіюванням/видаленням власних файлів у APPDATA та LOCALAPPDATA
в каталозі ChaosLIVE_by_Cloud. Видалення налаштувань/пакетів незворотне без резервної
копії. Деінсталятор їх не стирає. Можна не запускати TikTok, вимкнути рекламу і не
користуватись зовнішніми посиланнями. Запити про сторонні серверні журнали адресуйте
їх операторам. Немає прихованої передачі даних Cloud або продажу даних аудиторії.

## Сайт завантаження
Сайт розміщений на GitHub Pages. GitHub/CDN отримує IP-адресу та технічні журнали
HTTPS-запитів. Сторінка отримує від GitHub API лише відомості про останній публічний
реліз. На сайті немає аналітики, рекламних SDK, cookie-ідентифікаторів або форм збору
даних. Посилання monobank відкривається лише за вашим натисканням. Умови GitHub:
https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

Вибір теми та мови зберігається лише у localStorage цього браузера, не передається Cloud і не пов’язується з ідентифікатором користувача. Якщо сховище браузера недоступне, перемикачі працюють без збереження.
